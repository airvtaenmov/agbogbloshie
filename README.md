# АгбогБлоши / Agbogbloshie

Интерактивный художественный шифратор. Трёхмерный прибор, текстовый шифр, Unicode-помехи и звуковая среда. Вся обработка текста происходит в браузере. Проект не предназначен для защиты секретной информации.

## Публикация на GitHub Pages (бесплатно)

1. Создай публичный репозиторий `agbogbloshie` на https://github.com/new.
2. Распакуй ZIP. Загрузи **содержимое** архива в корень репозитория через Add file → Upload files. В корне должны лежать `index.html`, `favicon.svg`, `README.md`, а также папка `.github` с `workflows/pages.yml`. Сам ZIP не загружай. Если браузер пропустил папку с точкой, создай файл `.github/workflows/pages.yml` через Add file → Create new file и скопируй в него содержимое одноимённого файла из архива. Основная ветка — `main`.
3. В репозитории: Settings → Pages → Build and deployment → Source → **GitHub Actions** (не Deploy from a branch).
4. Открой Actions → Publish Agbogbloshie → Run workflow → main → Run workflow. Если сборка запустилась автоматически и уже успешна, повторный запуск не нужен.
5. После успешной сборки адрес сайта появится в Settings → Pages. Обычно это `https://ВАШ-ЛОГИН.github.io/agbogbloshie/`.

При публикации workflow скачивает Three.js r160 из официального репозитория и помещает его вместе с лицензией MIT в `vendor/`. После публикации браузер загружает всё с GitHub Pages, без CDN и API. Не требуется npm, сервер или ключи.

## Альтернатива без GitHub Actions

Если удобнее публикация прямо из ветки, создай папку `vendor` в репозитории и скачай в неё два файла из официального репозитория Three.js:
- [three.module.min.js](https://raw.githubusercontent.com/mrdoob/three.js/r160/build/three.module.min.js)
- [LICENSE](https://raw.githubusercontent.com/mrdoob/three.js/r160/LICENSE) — сохранить как `THREE-LICENSE.txt`.
Затем Settings → Pages → Source: Deploy from a branch → main → / (root) → Save. Папку `.github` в этом варианте можно не загружать.

## Локальный запуск

Скачай указанные два файла в `vendor/` и запусти из каталога проекта `python -m http.server 8000`, затем открой http://localhost:8000. При открытии index.html двойным кликом браузер может блокировать локальные JS-модули. Сайт не является установленным офлайн-приложением; для первого запуска требуется доступ к опубликованному сайту или локальный сервер.

## Управление

- Мышь: поворот прибора, колесо — приближение, двойной щелчок — исходный ракурс.
- F1 — сервисные параметры; F2 — диагностика; M — звук, либо SND ON/OFF.
- MIX / RESET — новый набор знаков / возврат предыдущего набора; COPY — копирование результата.
- На узком экране дополнительно доступны ТЕКСТ, COPY, СЕРВИС.
- Настройки и черновики хранятся локально в браузере. Старые алфавиты необходимо сохранять отдельно для дальнейшей расшифровки.

## Состав и права

`index.html` содержит шифратор, модель, материалы, звук и встроенные изображения. Фон — художественная генерация, а не документальная фотография. Three.js r160 распространяется по MIT; её лицензия включается в опубликованную сборку. Имя автора и условия распространения самого художественного проекта не указаны: добавь желаемую подпись в этот README перед публикацией. Публичный репозиторий раскрывает исходный код, но сам по себе не предоставляет открытой лицензии на проект.
